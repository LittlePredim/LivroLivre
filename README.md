# 📚 LivroLivre

Aplicativo desenvolvido em React Native para gerenciamento e troca de livros acadêmicos entre estudantes.

## Objetivo

O LivroLivre foi criado com o objetivo de facilitar a troca de livros acadêmicos, incentivar a reutilização de materiais de estudo e promover o acesso ao conhecimento entre estudantes.

## Funcionalidades

- Cadastro de livros
- Listagem de livros cadastrados
- Pesquisa por título
- Visualização de detalhes do livro
- Edição de informações
- Exclusão de livros
- Armazenamento local com SQLite

## Tecnologias Utilizadas

- React Native
- Expo
- SQLite
- React Navigation
- JavaScript

## Estrutura do Projeto

```text
database/
└── database.js

screens/
├── HomeScreen.js
├── AddBookScreen.js
├── EditBookScreen.js
├── BookDetailsScreen.js
└── AboutScreen.js
```

## Como Executar

1. Instalar as dependências:

```bash
npm install
```

2. Executar o projeto:

```bash
npx expo start
```
